# 연구실 머신러닝 세미나 기록

순천향대학교 연구실 세미나에서 진행한 머신러닝 기초, 심화, 강화학습 실습 노트북과 발표 자료입니다.

| 폴더 | 내용 |
|---|---|
| `ML_BASIC/no_1` ~ `no_5` | NumPy, 파이토치 기초, 선형 회귀, 로지스틱 회귀, 소프트맥스 분류, 퍼셉트론, ReLU, 가중치 초기화, 오버피팅, 배치 정규화, CNN(MNIST, CIFAR), VGG, Visdom 시각화 |
| `ML_BASIC/PPT` | 세미나 발표 자료 (1~7일차) |
| `SEMINAR_ML_Advanced` | CNN MNIST, 역전파 기울기 검사, 지수가중이동평균, 모멘텀 |
| `Reinforce Learning` | DQN, Target Network를 둔 DQN, DDQN, 시차 학습(TD) 실습과 보조 모듈 `RLHelper.py` |

- 실습용 노트북 모음이며 하나로 묶인 실행 진입점은 없습니다.
- `ML_BASIC/no_2/data/FashionMNIST/raw/`에는 torchvision이 내려받은 FashionMNIST 원본이 그대로 들어 있습니다.
- `.ipynb_checkpoints/` 폴더는 Jupyter 자동 저장본입니다.
